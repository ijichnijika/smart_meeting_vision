# 智能会议签到与出勤分析系统 (Smart Meeting Vision System)

面向企业会议与学术研讨场景的桌面端智能视觉管理软件，结合“传统桌面 MIS 业务管理 + 深度学习视觉感知”，实现会议实时点名签到、在席人数统计、分心行为检测与考勤数据报表分析。

---

## 🚀 快速开始

### 1. 克隆项目
```bash
git clone 
cd python_project
```

### 2. 环境配置
建议使用 Python 3.10+ 环境：
```bash
# 创建虚拟环境
python3 -m venv .venv

# 激活虚拟环境
# macOS / Linux:
source .venv/bin/activate
# Windows:
# .venv\Scripts\activate

# 安装依赖
pip install -r requirements.txt  # 或 uv sync
```

### 3. 运行程序
```bash
python main.py
```
